# TrustVault – AI Prompts and Development Assistance

## 1. Project Planning
**Prompt:** Suggest a secure document management and sharing system using Python Flask.

**Purpose:** To understand the project requirements, features and technology stack.

## 2. User Authentication
**Prompt:** Help implement user registration and login using Flask and SQLite with password hashing.

**Purpose:** To create secure user authentication.

## 3. Role-Based Access Control
**Prompt:** Explain how to implement Admin, Owner and Viewer roles in Flask.

**Purpose:** To restrict access based on user roles.

## 4. Document Management
**Prompt:** Help create document upload, download, update and delete functionality using Flask.

**Purpose:** To manage user documents.

## 5. Document Sharing
**Prompt:** Explain how to share documents with registered users using read and edit permissions.

**Purpose:** To implement controlled document sharing.

## 6. Permission Revocation
**Prompt:** Help implement permission revocation so users immediately lose access after their permissions are removed.

**Purpose:** To protect shared documents.

## 7. Document Version History
**Prompt:** Help implement document version history when a shared document is updated.

**Purpose:** To maintain previous document versions.

## 8. Audit Logging
**Prompt:** Explain how to record document uploads, downloads, updates, deletions and unauthorized access attempts.

**Purpose:** To maintain an activity history.

## 9. Security Testing
**Prompt:** Help write Pytest test cases to verify that users cannot access documents without permission.

**Purpose:** To test application security.

## 10. Debugging
**Prompt:** Help identify and fix Flask errors, Python errors and failing automated tests.

**Purpose:** To improve application reliability.

## Conclusion
AI assistance was used to understand concepts, plan features, debug errors and develop test cases. The project was implemented and tested step by step.
